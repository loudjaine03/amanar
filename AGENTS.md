## What Lovable manages

Rules outside this block are the project's own. Change the pieces below in
Lovable, not by hand. With the [Lovable MCP](https://mcp.lovable.dev)
connected, `send_message` asks Lovable to do it; otherwise ask the user to
use the editor.

- **Database.** Do not add or edit `supabase/migrations/` or `drizzle/`.
  Ask Lovable to change the schema.
- **Generated files.** Do not edit a file whose header says it is automatically
  generated.
- **AI gateway.** Keep model calls on Lovable's gateway, and keep
  `LOVABLE_API_KEY` out of browser code.
- **Connectors.** Lovable provides native connectors. `list_connectors` shows
  which are enabled; `add_connector` only returns the dashboard link. When a
  connector is enabled, calls go through the connector gateway and need
  `LOVABLE_API_KEY`. When Lovable does not provide one, users can bring their
  own key and store it in Secrets.
- **Secrets.** Lovable manages them. Do not put secret values in the repo.

## App architecture
- TanStack Start file-based routing: `/` (home, destination cards), `/plan` (step 1: user choices + live kNN twin model), `/compare`, `/site`, `/rehearse`, `/method`, `/report` (printable results, Save as PDF via the print dialog). The mission shell wraps the root Outlet.
- ML in the browser: `src/lib/twins.ts` (kNN on `public/ml/twins.json`), `src/lib/plan.ts` (ranking rules per goal), `src/lib/materials.ts` (materials, crew safety, pressure physics), `src/lib/sensors.ts` (route sensor simulation). `src/test/twins.test.ts` checks the browser model reproduces the pipeline's predictions.
- The app only reads static files: `public/mission_data.json` (version 2), the overlays and the grids. No server, no database.
- `public/mission_data.json`, `public/ml/`, `public/overlays/` and `public/grids/` are generated by `pipeline/build_all.py` (Earth) and `pipeline/compare.py` (comparison with Mars and the Moon); edit `pipeline/content.py` and rerun instead of editing them by hand.
- Never fabricate measurements: unknown values stay null (shown as TBD). Geology never changes the terrain score.
